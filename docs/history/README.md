# docs/history — 동결된 역사 (편집 금지)

여기는 DMS 를 지은 과정의 **역사적 근거**다. 슬라이스별 설계문서가 들어 있다.

## 규칙

- **편집하지 마라.** 이 문서들은 작성 시점의 사실이고, 그대로 둔다. 오타·라인 드리프트도
  고치지 않는다 — 역사는 당시 그대로가 정확한 기록이다.
- **현재 동작을 여기서 찾지 마라.** 시스템이 지금 어떻게 도는지는
  [`../../ARCHITECTURE.md`](../../ARCHITECTURE.md)와 코드의 「왜」 주석이 정의한다.
  이 설계문서들은 "그때 왜 그렇게 하기로 했나"의 근거일 뿐, 이후 슬라이스가 전제를
  바꿨을 수 있다(각 설계의 「전제 재확인」 절이 그 드리프트를 기록한다).
- 문서 안의 경로 참조(`docs/superpowers/...` 등)는 작성 당시의 것이다. 현재 위치와
  다를 수 있으나 고치지 않는다(동결).

## 무엇이 있나

- `specs/` — 슬라이스별 설계(design). 각 문서의 값어치:
  - **「실측으로 확인한 전제」** — 그 슬라이스가 코드를 읽고 확인한 사실
  - **「핵심 결정」** — 무엇을 왜 그렇게 하기로 했나
  - **「이 슬라이스에서 하지 않는 것」** — 의도적으로 자른 범위(왜 지금의 시스템이 그런지)

## 어디로 갔나

- **구현 플랜(TDD 스크립트)** — 일회성이라 워크트리에서 지웠다. `git log --follow
  docs/superpowers/plans/` 로 복구 가능(git 이력에 영구 보존).
- **완료 슬라이스 기록** — [`../../CHANGELOG.md`](../../CHANGELOG.md)로 옮겼다.
- **원본 마스터 설계**(`clean-slate-design.md`)도 여기 `specs/` 에 있다 — 2026-08-05
  이후 갱신 안 됨. 원래 계획이지 지어진 시스템이 아니다(현재 상태는 ARCHITECTURE.md).
